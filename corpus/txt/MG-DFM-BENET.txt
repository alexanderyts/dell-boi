Easily integrate hardware, upgrade SONiC software packages, and deploy perfect device configurations in a modern UI or with a unified set of fabric APIs. Try Now What is SONiC? Software for Open Networking in the Cloud (SONiC) is a modern network operating system (NOS) that powers ethernet network hardware. SONiC is an open source, containerized platform capable of operating the large networks in the world. Dell’s Enterprise SONiC software runs on a wide portfolio of PowerSwitch platforms, including models designed for spine-leaf data center architectures, edge deployments, and high-performance computing environments. Customers benefit from the scale, port density, and hardware diversity of Dell switches while maintaining control over the software stack through open APIs and a standardized CLI experience. Unlike community builds of SONiC, Dell SONiC includes a fully integrated, tested, and supported software package. Dell provides long-term support releases that include security patches, hardware-specific enhancements, and regression-tested features. Customers also have access to Dell’s world-class global support organization, which brings extensive networking expertise, proactive service capabilities, and enterprise-grade SLAs.
