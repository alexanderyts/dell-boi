Introduction: Test setup
Introduction
Dell Technologies offers two enterprise-class network operating systems (NOS) for enterprise, cloud, and edge deployments. This tech brief compares some of the most common configurations deployed within these areas. This document is not exhaustive and does not cover all commands and configurations. Instead, the document provides a glimpse into each NOS and offers a brief command-line interface (CLI) comparison.
NOTE: As CLI syntax may change, Dell Technologies recommends checking each NOS user guide in References.
Environment details
This document is divided into Layer 2 and Layer 3 components and their configurations. The following figure shows a typical Layer 3 leaf-and-spine Clos architecture using BGP EVPN VXLAN. The test setup consists of: ● Two spine switches—Z9432F-ON ● Six leaf switches—S5248F-ON ● Two external routers ● Nine hosts allocated as:
○ Six servers belonging to different groups (Marketing, Engineering, Sales) ○ Three VxRail appliances

Network operating system feature configurations: Deployment

Document structure

The configuration structure that this document describes is broken down into specific features for simplicity: Layer 2, Layer 3, and Miscellaneous. This document does not describe the configurations of all the devices as they are largely similar. The devices that this chapter describes include Leaf1, Spine1, and BLeaf1.
NOTE: Dell SONiC is compatible with open-source SONiC; the default CLI prompt is the open-source SONiC (admin@hostname:~$). With a Dell switch running Dell SONiC, load the Dell SONiC Management Framework CLI (MF-CLI) to configure the switch using the familiar CLI interface.
The following commands show how to load the Dell SONiC MF-CLI from the default prompt and configure standard interface naming:
sonic login: admin Password: admin@sonic:~$ sonic-cli sonic# conf t sonic(conf)# interface-naming standard sonic(conf)# exit
The default Dell SONiC password is "YourPaSsWoRd" (no double quotes).

Link tracking configuration

Link tracking includes both downstream and upstream interfaces. Tracking the state of the interfaces ensures that traffic convergence accounts for the status of all devices in the fabric before any data is placed on the fabric.
The following table shows the link tracking configuration:

Table 8. Link tracking configuration Device(s) - Leaf1, Spine1, BLeaf1 Dell SmartFabric OS10

Dell SONiC

conf t uplink-state-group 1 name "Virtual-switch-fail-over" enable downstream ethernet1/1/5 upstream ethernet1/1/3 upstream VLTi end

conf t link state track VIPinterfaces downstream all-mclag exit conf t interface Eth1/3 link state track VIPinterfaces upstream end
