Q: How complicated or easy is it to deploy Dell Networking to support my AI solutions? A: Dell Networking solutions (hardware and software) are based on industry open-standards, allowing for interoperability with other vendors. Deploying Dell Networking is not complicated. Configuration uses standard CLI commands for both AI and non-AI workloads. Furthermore, Dell Technologies has Fabric Manager, an orchestration tool that automates the deployment of AI and non-AI fabrics through a single-pane-of-glass graphical user interface. Q: Can we create multitenancy on the East-West GPU fabric (GPUaaS)? A: Yes. Using BGP EVPN VXLAN, the GPU fabric can be configured to provide multitenancy. Q: Does the East-West fabric offer redundancy for the GPU systems? A: Yes. Using a pure rail or rail-optimized design, GPU communication redundancy can be implemented. With a rail or rail-optimized design, a set of GPUs is connected to a dedicated switch rail. Each GPU has two connections: ● An internal proprietary high-speed connection implemented by the GPU vendor ● A network connection to the dedicated switch rail, typically 400GbE or 800GbE The following figure shows the redundant connection highlighted by the purple line.

Figure 3. Rail-Optimized GPU backend fabric
In this scenario, a GPU connected to the black switch rail communicates with a GPU connected to the purple switch rail. If the connection to the black switch rail fails, the internal connection is used to communicate with the GPU on the purple rail, ensuring redundancy. Q: How can we create virtual environments for remote customers that connect to the N/S side of the host systems? A: Every AI solution has three fabrics: out-of-band, frontend, and backend. The frontend fabric, with BGP EVPN VXLAN deployed, provides connectivity to the North-South side of the host system. Q: Which technology is more suitable to offer multitenancy (IB or Ethernet)? A: Both technologies provide multitenancy. Each has its own advantages and disadvantages.

Q: What switching operating system features do I need for a multitenancy AI workload environment?
A: BGP EVPN VXLAN is the key feature to deliver multitenancy services for an AI environment. This feature allows the extension of Layer 2 networks (VLANs) across a scalable Layer 3 cloud.
For more information about Dell SONiC BGP EVPN VXLAN, refer to the Dell SONiC VXLAN user guide.
Q: How is network bandwidth scaled linearly as new NICs for GPU nodes are added?
A: There are two commonly used networking fabrics for GPU cluster deployments:
● Pure rail ● Rail-optimized
Both designs use dedicated switching fabric. As GPUs are added and the dedicated switching fabric runs out of ports, additional switches are added to the fabric to enable horizontal scalability.
Q: Can we use single GPU backend/Compute/E-W fabric for different use cases like training plus inferencing and for different GPU types?
A: Yes, the same backend fabric can be used for training, inference, and fine-tuning with proper job scheduling. However, training usually requires full GPU cluster access, while inference and fine-tuning do not.
Using a common backend fabric across different GPUs is not recommended, as each GPU architecture is different and each network fabric is purposely implemented based on the type of GPU (NVIDIA, AMD, Intel).
Q: What are the scaling considerations for AI Storage traffic?
A: Consider the following best practices when integrating or deploying storage for AI workloads:
● Provide line-rate access to storage traffic by maintaining 1:1 oversubscription to handle intermittent traffic spikes. ● Always use the maximum MTU (jumbo frames) across the network. ● Minimize latency by prioritizing storage traffic within the fabric providing storage services.
Q: Are there any guidelines for redundancy, scalability, and oversubscription in storage fabrics?
A: Yes. The following are recommended guidelines:
● Use redundant switching fabrics (for example, two leaf switches) whenever possible. ● Deploy dual-homed links from each storage appliance towards the switching fabric. ● Maintain 1:1 oversubscription where possible. Otherwise, 2:1 is the minimum recommended.
Q: Do you have benchmark reports for specific GPUs and switches that show network performance, latency values, and congestion prevention?
A: Yes. Dell Technologies has conducted benchmark testing using the Dell PowerSwitch Z9664F-ON, with results published in a Tolly Group report.
